# OnlyPlans

Общий проект команды из четырёх человек: инструмент для планирования продуктового роадмапа.

## Первая версия (предложение для обсуждения)

- Создание и редактирование инициатив: название, описание, ответственный, статус, сроки.
- Просмотр инициатив на временной шкале.
- Фильтры по статусу и ответственному.
- Сохранение данных между посещениями.

Стек, авторизация, совместное редактирование и размещение пока не выбраны. Приложение ещё не реализовано; команды запуска появятся после выбора стека.

## Работа команды

1. Принять приглашение в репозиторий и клонировать его.
2. Перед работой обновить main: `git switch main`, затем `git pull --ff-only`.
3. Создать ветку: `git switch -c feature/short-task-name`.
4. Открыть эту папку в редакторе. Передать агенту: «Прочитай AGENTS.md и соблюдай его, включая личные журналы».
5. Делать небольшие коммиты и отправлять ветку: `git push -u origin HEAD`.
6. Создать Pull Request в main, получить проверку одного коллеги и объединить изменения.

Не хранить пароли, ключи и персональные данные в репозитории. Не редактировать одну задачу параллельно без согласования.

## Журналы

Правила находятся в AGENTS.md, команды — в docs/logging.md. Каждый участник использует свой GitHub-логин. Журналы входят в коммиты вместе с работой.
