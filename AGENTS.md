# Обязательные правила агентов OnlyPlans

Прочитай docs/logging.md и .agents/skills/project-journal/SKILL.md. Единственный журнал — logs/, команды scripts/journal.mjs.

1. До работы открой сессию на подтверждённый GitHub-логин участника. git user.name не обязательно GitHub-логин; если неизвестен, уточни. Не записывай под чужим именем.
2. Один start создаёт три поджурнала с общим ID: logs/work/<login>/, logs/decisions/<login>/, logs/usage/<login>/. Не открывай параллельную запись в старом формате. Для каждого участника отдельная сессия.
3. По ходу фиксируй решения: контекст, выбор, альтернативы, причина, последствия. Записывай реальные режимы, модели, скиллы, плагины, MCP и инструменты. Не выдумывай данные. Если решений нет, поясни в результате.
4. Точные токены — из usage со ссылкой на источник и охват. Неизвестные — null. Оценки только по явному запросу, отдельно от точных данных. Не суммируй кумулятивные снимки и вложенные cached/reasoning повторно.
5. Перед финальным ответом проверь три поджурнала и закрой сессию. При продолжении начни новую. Не выдумывай время конца оборванной сессии. Длительность включает ожидание, это не активные часы человека.
6. Перед PR выполни node scripts/journal.mjs check. Включи JSON и автоматически обновлённые README журналов. Ревьюер проверяет записи каждого участника. Публикуй только при разрешении пользователя.
7. Не сохраняй секреты, полные переписки и личные данные. Не меняй чужие журналы. original_sources и logs/migration.json — неизменяемые доказательства переноса, а не второй журнал для заполнения.
