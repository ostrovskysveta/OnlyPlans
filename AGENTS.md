# Обязательные правила для всех агентов OnlyPlans

В начале каждой рабочей сессии прочитай этот файл. Определи GitHub-логин человека из контекста или локального git config user.name. Если он неизвестен, уточни его; не используй чужой логин.

1. До изменений запусти scripts/session.ps1 start с логином и задачей. Сохрани возвращённый SessionId. Если команду запустить нельзя, создай эквивалентные JSON-журналы вручную и сообщи об ограничении.
2. До завершения ответа выполни stop. Длительность — календарное время между start и stop, включая ожидание. При возобновлении работы начни новую сессию. Не выдавай это время за активные часы человека. Незакрытая сессия остаётся незакрытой: не придумывай время окончания.
3. Токены записывай только по данным среды/API с указанием источника и области измерения. Если точных данных нет, оставь null и причину. Никогда не подменяй отсутствие данных нулём или оценкой. Не суммируй повторно накопительные значения.
4. Веди личный лог решений: контекст, выбранный вариант, альтернативы и последствия. Записывай существенные решения через decision; если решений не было, явно укажи это в итоговом Summary.
5. Через usage фиксируй каждый реально использованный режим, скилл, плагин и инструмент: точное имя, тип, цель. Повторные вызовы одного инструмента с той же целью можно объединить. Доступный, но не применённый инструмент не считается использованным. Неизвестное имя модели/режима не выдумывай.
6. Перед коммитом проверь личные логи и закрой сессию. Не меняй журналы коллег, не записывай секреты, полные промпты или закрытые пользовательские данные.

Это обязательный рабочий протокол, а не техническая гарантия поведения любого агента. Проверяющий PR должен проверить наличие журналов. Команды и формат: docs/logging.md.
