# Инициатива OnlyPlans

> Статус: инициация (kickoff). Дата: 2026-11-09.

## Цель

Создать инструмент **OnlyPlans** для ведения и создания роадмапов команд
(в первую очередь — ИТ-команд).

Инструмент должен позволять команде:

- фиксировать цели и инициативы на горизонт (квартал / полугодие);
- видеть зависимости, сроки и владельцев;
- поддерживать роадмап в актуальном состоянии по мере изменения приоритетов;
- давать общий источник правды (single source of truth) для планирования.

## Проблема / гипотеза

Команды ведут роадмапы в разных местах (таблицы, слайды, вики), они быстро
устаревают и не отражают реальное состояние работы. Гипотеза: централизованный,
структурированный инструмент снизит стоимость поддержки роадмапа и повысит
прозрачность планов.

## Пользователи

- Лиды / тимлиды команд — ведение и презентация роадмапа.
- Участники команды — понимание целей и приоритетов.
- (Возможно) вышестоящие stakeholders — обзор планов.

## Scope (черновик, требует уточнения)

**Входит (initial MVP):**
- модель роадмапа: инициативы / эпики, сроки, статусы, владельцы, зависимости;
- UI для создания и редактирования роадмапа;
- простое отображение (timeline / таблица).

**Открытые вопросы (нужно решить):**
- веб-приложение vs CLI vs библиотека/документ-генератор;
- хранение данных (файлы/БД/облако) и формат;
- интеграции (Jira, GitLab и т.п.) — на каком этапе;
- аудитория: один пользователь-лид или вся команда (совместное редактирование).

## Метрики успеха (гипотеза, уточняется)

- Стоимость обновления роадмапа после изменения приоритетов (время).
- Частота актуализации роадмапа командой.
- Доля «живых» (актуальных) роадмапов в команде.
- Удовлетворённость команды инструментом.
