# OnlyPlans — Глоссарий
| Термин | Определение |
|---|---|
| Роадмап | План команды и граница конфигурации/доступа. |
| Команда | Группа пользователей, работающих с одним или несколькими роадмапами. |
| Участник роадмапа | Пользователь с назначенной ролью в конкретном роадмапе. |
| Инициатива | Продуктовый замысел типа «идея» или «исследовательская инициатива». |
| Исследовательская инициатива | Инициатива для исследования/проверки гипотезы; может завершиться без фичи. |
| Фича | Планируемая продуктовая возможность в рамках инициативы. |
| Этап | Пользовательски определяемая часть процесса конкретной фичи. |
| Задача | Конкретная работа внутри этапа; может иметь тип, статус, сроки, исполнителей и дочерние задачи. |
| Тип задачи | Классификация работы; справочник уровня роадмапа. |
| Статус задачи | Текущее состояние задачи; справочник уровня роадмапа. |
| Терминальный (веховый) статус | Статус, отмечающий достижение значимой контрольной точки, например «Готово к тестированию» или «Готово к релизу». |
| Веха | Зафиксированное событие достижения задачей терминального/вехового статуса. |
| Исполнитель | Участник роадмапа, назначенный на задачу. |
| Представление | Способ отображения общих объектов, например календарь Discovery или Delivery. |
| Видимость | Персональная настройка отображения задачи в представлении; не право доступа. |
| Пересечение | Совпадение интервалов задач одного исполнителя минимум на один рабочий день. Не доказывает перегрузку. |
| Зависимость | Связь между задачами, задающая ограничение порядка выполнения. |
| Пресет длительности | Шаблон длительности типовой задачи. |
| Роль | Базовый набор прав: владелец, редактор или читатель в конкретном роадмапе. |
| Контекстное разрешение | Дополнительное право по контексту, например смена статуса назначенной задачи. |
| История изменений | Аудит общих полей с автором, временем и прежним/новым значением. |

## Не смешивать
- Этап ≠ статус: этап относится к процессу фичи, статус — к состоянию задачи.
- Тип задачи ≠ этап: тип классифицирует работу.
- Веха ≠ этап: веха фиксирует событие достижения контрольной точки.
- Видимость ≠ доступ: скрытие не запрещает доступ и не удаляет данные.
- Пересечение ≠ перегрузка: нет оценки трудозатрат.
- Инициатива ≠ фича: исследование может не перейти в разработку.
