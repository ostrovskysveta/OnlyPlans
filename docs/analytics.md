# Аналитика

Единственный журнал — [logs](../logs/README.md). [Правила и команды](logging.md).

Команда node scripts/journal.mjs report строит сводку по участникам. Она также появляется в GitHub Actions → Analytics → Summary. Точные токены, оценки и неизвестные значения разделены. Время календарное, с ожиданиями.

Старые logs и analytics перенесены в единый журнал. Реестр: logs/migration.json. Полные исходные тексты и SHA-256 сохранены в original_sources записей работы. Это архивные доказательства, заполнять их повторно не нужно.
