# Подключение к GitHub — инструкция для участников команды

Эта инструкция поможет настроить доступ к GitHub на твоём Mac, чтобы ты мог(ла) работать
с репозиторием команды OnlyPlans. Всё делается в несколько простых шагов.

---

## Что понадобится

- Mac.
- Приложение **«Терминал»** (Terminal) — находится в папке «Программы» → «Утилиты»,
  или через поиск Spotlight (⌘ + Пробел → введи «Терминал»).
- Учётная запись GitHub (если нет — зарегистрируйся на https://github.com).

---

## Шаг 1. Установи программу GitHub CLI (`gh`)

GitHub CLI — это программа, которая упрощает работу с GitHub.

### Способ А — если есть Homebrew (проще)

Открой Терминал и вставь команду:

```bash
brew install gh
```

Дождись окончания установки и переходи к Шагу 2.

### Способ Б — если Homebrew нет (ручная установка)

1. Узнай тип своего Mac: меню  → «Об этом Mac» → вкладка «Обзор» → «Чип».
   - Если написано **Apple M1 / M2 / M3 / M4** — твой Mac на Apple Silicon.
   - Если **Intel** — Mac на Intel.
2. Открой страницу загрузок GitHub CLI: https://github.com/cli/cli/releases/latest
3. Скачай подходящий архив (ZIP):
   - Apple Silicon → файл с именем вроде `gh_2.103.3_macOS_arm64.zip`
   - Intel → файл вроде `gh_2.103.3_macOS_amd64.zip`
4. Распакуй скачанный ZIP (двойной клик по файлу).
5. В Терминале выполни команды (скопируй целиком и вставь):

```bash
mkdir -p ~/.local/bin
cp ~/Downloads/gh_*/bin/gh ~/.local/bin/gh
chmod +x ~/.local/bin/gh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

> Команды просто создают папку, копируют программу и добавляют её в «поиск команд».
> Ничего не сломают.

---

## Шаг 2. Проверь установку

В Терминале выполни:

```bash
gh --version
```

Если всё ок — увидишь что-то вроде `gh version 2.103.3 …`. Значит программа установлена.

---

## Шаг 3. Войди в свою учётку GitHub

Выполни:

```bash
gh auth login
```

Дальше отвечай на вопросы (стрелками выбирай нужный вариант, затем Enter):

1. **«What is the preferred protocol for Git operations?»** → выбери **HTTPS**.
2. **«Authenticate Git with your GitHub credentials?»** → выбери **Yes**.
3. Программа покажет **одноразовый код** и адрес **https://github.com/login/device**.
   - Открой этот адрес в браузере.
   - Введи показанный код.
   - Подтверди доступ (поставь галочки на правах **repo** и, если нужно, **workflow**).
4. Вернись в терминал — там появится сообщение **«Logged in as …»**.

Готово, ты вошёл(а) в GitHub.

---

## Шаг 4. Проверь, что всё работает

Выполни:

```bash
gh auth status
```

Ожидаемый результат: `✓ Logged in to github.com account ТВОЙ_ЛОГИН`.

---

## Что дальше

Ты подключён(а) к GitHub. Дальнейшие шаги по работе с репозиторием команды (как клонировать,
создавать ветку, коммитить и делать pull request) описаны в файле **`AGENTS.md`** этого
репозитория — прочитай его и следуй инструкциям.

---

### Если что-то не получилось

| Ситуация | Что делать |
|---|---|
| `gh: command not found` | Проверь Шаг 1: программа не в PATH. Переустанови или повтори `source ~/.zshrc`. |
| Браузер не открывает код | Вручную набери https://github.com/login/device и введи код. |
| «Authenticated as …» не появилось | Повтори `gh auth login` с начала. |
| Ошибка про права (`workflow` и т.п.) | Подтверди в браузере нужные галочки при авторизации. |
